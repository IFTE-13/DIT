# DIT — Modern SaaS & Prototype Landing Page

A minimal, professional, and responsive single-page landing page built with semantic **HTML5**, modern **CSS3**, and lightweight **Vanilla JavaScript**. 

Designed as a front-end practice project inspired by clean SaaS and product landing page standards, featuring a custom browser tab icon (favicon), standardized assets architecture, and responsive design best practices.

---

## ✨ Features

- **Custom Favicon & Tab Icon**: High-definition SVG and multi-resolution PNG/ICO browser icons matching the brand identity.
- **Hero & Free Trial Conversion**: High-impact value proposition with a quick sign-up card and download call-to-action.
- **Interactive Tabbed Showcase**: Smooth, accessible tabbed switching to highlight features without page reloads.
- **Feature Highlights & Cloud Sync**: Clean sub-list and graphic sections detailing core capabilities.
- **Value Propositions Grid**: 3-column benefit cards ("Thoughtful Design", "Well Crafted", "Easy to Customize").
- **Tiered Pricing Tables**: Clear comparison tiers (Basic, Professional, Enterprise) with a highlighted popular plan.
- **Customer Testimonials**: Speech-bubble quote cards with author avatars and job titles.
- **High-Contrast CTA Banner**: Prominent call-to-action banner for maximum conversion.
- **Contact Form**: Responsive message form with client-side feedback.
- **Fully Responsive**: Mobile-first fluid layout adapting seamlessly from smartphones to 4K displays.

## 🛠️ Tech Stack

- **HTML5**: Semantic tags (`<header>`, `<nav>`, `<section>`, `<footer>`), ARIA accessibility labels, and clean meta tags.
- **CSS3**: Native CSS custom properties (variables), Flexbox, CSS Grid, smooth transitions, and organized media queries.
- **Vanilla JavaScript**: Zero heavy framework dependencies for interactive components (tab switching, scrollspy navigation, form handlers).
- **Bootstrap 4 Grid**: Utilized for standard grid containers and columns.
- **Font Awesome 4.7 & Google Fonts**: 'Raleway' and 'Open Sans' typography.
